**Files:**
- Modify: `bin/houserules.mjs` (`install`; new module-local `renderIn`),
  `tests/init.test.mjs`

**Behavior:** `install` calls `renderIn(target)`, which runs
`execFileSync(process.execPath, [join(target, 'tools/kb.mjs'), 'render'],
{ cwd: target, encoding: 'utf8', stdio: ['ignore', 'pipe', 'pipe'] })` and
returns its stdout. When the child fails, `renderIn` throws `UsageError`
with the child's stderr, trimmed (fallback text `tools/kb.mjs render
failed` when stderr is empty). `main` already prints a `UsageError` as one
`error` line and returns 2. Verify against the current Node `child_process`
docs that an explicit `stdio` stops the echo of the child's stderr and that
`error.stderr` is a string under `encoding: 'utf8'`; record it in
`docs_verified`.

  `io.stderr` matches `/knowledge\/process\.json: invalid JSON/`, contains

`not triggered` (unchanged); with `ctx.report` → unchanged; with
`ctx.reports`: the reports whose `files_changed` match `if` are the hits; no
hit → pass with evidence `not triggered by any report`; a hit whose field is
missing → fail `<name> lacks a value for <field> (triggered by <file>)`;
all hits set → pass with evidence `report field <field> is set in <k>
reports`; neither option → `skipped` as today.
