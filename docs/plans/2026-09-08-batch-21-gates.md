HR-076, HR-086)

list declares globs that match zero tracked files fails with
the area and globs named; a deliberately empty paths list stays
legal (the process area). check-backlog gains the emitter
round-trip: parse, re-emit through the shipped serializer,
byte-compare; divergence names the file — the check REUSES the
shipped emit path, never a second serializer (the incident was

textList minLength in BOTH copies (template first, update
resyncs; the copies stay byte-identical), with the nine-field
enumeration from HR-086 bounding the change; every tracked
deliverable fixture re-validates, and the deliberately-invalid
fixtures stay invalid for their ORIGINAL reasons (the task
proves both directions). TDD per gate: the seeded incident
instance RED, verbatim, then clean at HEAD.

### T2 — the report/audit-side gates (spec §3, §5; HR-075,
HR-077)

check-report-claims gains the ephemeral-path check: a cited
artifact path under /tmp/ or a session-scratchpad pattern in
any scanned narrative field flags deterministically; an honest
Limits bullet states what it cannot see (a durable-looking path
that is still uncommitted, for instance). audit gains the
sanctioned-fail annotation: the task defends the CLI shape
against the current grammar (e.g. `--sanctioned <rule>=<ref>`,
repeatable), the JSON row's evidence carries the declaration,
and every doc/skill sentence that names an audit invocation
sweeps in the same task (enumeration-first). The annotation is
proven by running the consumer: an audit over a range with a
booked fail reads pass-with-sanction downstream exactly once.
