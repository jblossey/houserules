### Task 2: symlink-safe entry guard (HR-001)

**Files:**
- Modify: `template/tools/lib/cli.mjs` (new export), `template/tools/kb.mjs`,
  `template/tools/backlog.mjs`, `bin/houserules.mjs` (guards),
  `tests/cli.test.mjs` (unit tests)
- Create: `tests/entry.test.mjs` (child-process tests through a symlink)
- Synced by `node bin/houserules.mjs update --dir .`: `tools/lib/cli.mjs`,
  `tools/kb.mjs`, `tools/backlog.mjs` (never edit these by hand;
  `houserules.template-is-the-source`; `tests/dogfood.test.mjs` pins them).

**Interface:** `isMainModule(moduleUrl: string): boolean` in
`template/tools/lib/cli.mjs`. True when `process.argv[1]` is set and its
real path (`realpathSync`) equals the real path of
`fileURLToPath(moduleUrl)`; false when `argv[1]` is absent, names a missing
path, or names another file. Doc comment states the symlink case (a package
manager's bin link or a symlinked package directory). Node built-ins only.

**Steps:**

- [ ] **Step 1: Failing unit tests** in `tests/cli.test.mjs`: save
  `process.argv[1]`, restore in `finally`/`afterEach`. Cases: (a) a temp
  symlink to `template/tools/lib/cli.mjs` itself as `argv[1]` → `true`
  (fails RED: export missing); (b) the direct real path → `true`; (c) another
  existing file → `false`; (d) `argv[1]` unset → `false`; (e) a path that
  does not exist → `false`. Run the focused file; keep the RED output.

- [ ] **Step 2: Failing end-to-end tests** in `tests/entry.test.mjs`: for
  each of `bin/houserules.mjs files`, `template/tools/kb.mjs topics`,
  `template/tools/backlog.mjs list`: create a temp dir, `symlinkSync` the
  file into it, run `execFileSync(process.execPath, [link, ...args], {
  cwd: <repo root>, encoding: 'utf8' })`, `JSON.parse` the stdout and assert
  a known key (`kitOwned`; a topics array containing `houserules`; an items
  array). RED: stdout is empty, `JSON.parse` throws.

- [ ] **Step 3: Implement.** Add `isMainModule` to `cli.mjs` (import
  `realpathSync` from `node:fs`, `fileURLToPath` from `node:url`). Replace
  the guard in the three CLIs with `if (isMainModule(import.meta.url)) {`;
  drop imports that become unused (`pathToFileURL`, `resolve` where nothing
  else uses them). Run `node bin/houserules.mjs update --dir .`; check the
  three root copies changed and nothing else.

- [ ] **Step 4: GREEN.** Focused files, then `mise run test` (all tests,
  coverage thresholds met; state the measured line and branch percentages in
  `coverage`).

- [ ] **Step 5: Live run.** Commit first (`fix(cli): resolve the entry path
  through symlinks before the main-module check`). Then, in a scratch
  project under the session scratchpad: `mise x node@24.18.1 pnpm@11.18.0 --
